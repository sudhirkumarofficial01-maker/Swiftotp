# SwiftOTP
Node.js + Express starter for an authorized SMS verification platform.

Render:
- Runtime: Node
- Build Command: npm install
- Start Command: npm start
- Root Directory: blank
- Free instance is fine for initial testing.

Never commit .env or provider secret keys.

This starter does not implement disposable-number OTP interception, OTP harvesting, or third-party verification bypass. Connect an approved transactional SMS/Verify provider for legitimate, consented verification.
